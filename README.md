## About

Full-stack engineer with hands-on experience in cloud infrastructure,
Kubernetes, and big data pipelines.

Focused on **agent harness engineering** — the infrastructure layer around
LLM applications that determines whether AI systems actually work in
production: context, tools, orchestration, and reliability.

An advocate for AI adoption inside organizations — exploring best practices
and helping engineering teams build with AI effectively.

Contributing to open source out of genuine interest, mostly at the
intersection of big data and AI agent infrastructure.
